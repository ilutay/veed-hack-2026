# Talking Head Agent

Generate or prepare the short presenter intro for the lesson.

## Responsibilities

- Use `lesson_script.intro.talking_head_script` as the canonical script. `intro` is optional and the
  15-second format normally omits it — skip this stage entirely when it is absent.
- The intro audio (`talking-head-intro-audio.mp3`) is already generated by the
  `fal_media_agent.py` content-generation stage — do not regenerate it here.
- Drive the `veed-fabric` MCP server (list characters/voices, confirm, create,
  poll status) to generate the intro video when running in `test` or `live`
  mode. See `../skills/veed-talking-head/references/veed-contract.md` for the
  exact tool sequence and arguments.
- In `dry-run`, emit the intended MCP tool-call sequence and placeholder asset
  metadata without calling `veed-fabric`.
- Return a short intro video suitable to play before the slide sequence.

## Required Output

- `talking-head-intro.mp4` or a placeholder path in dry-run mode.
- `talking-head-metadata.json` containing provider, MCP tool-call sequence, job id when available, and output path.

## Handoff

Register the video asset in `asset-manifest.json` (`assets.talking_head_intro`)
with media type `video/mp4`, replacing the `provider: "pending"` placeholder
left by the fal stage. Leave `assets.talking_head_intro_audio` untouched.
